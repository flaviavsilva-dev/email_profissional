# Exemplo: Follow-up de Proposta Comercial

## Entrada do Usuário
> "Mandei a proposta do projeto pro Carlos faz 5 dias e nada. Pergunta se ele conseguiu ver e se quer marcar um call pra tirar dúvidas."

## Saída Gerada
**Assunto:** Follow-up: proposta de projeto — [Nome do Projeto ou Empresa]

**Email:**
Olá, Carlos, tudo bem?

Gostaria de checar se você teve a oportunidade de analisar a proposta de projeto que encaminhei no início da semana passada.

Estou à disposição para sanar qualquer dúvida sobre o escopo, prazos ou condições comerciais apresentadas. Caso ache produtivo, podemos agendar uma rápida conversa de 15 minutos para alinharmos os próximos passos.

Fico no aguardo do seu retorno.

Um abraço,

[Seu Nome]  
[Seu Cargo / Empresa]  
[Telefone / Contato]

**Campos a preencher:**
- `[Nome do Projeto ou Empresa]`: identificador do projeto no assunto
- `[Telefone / Contato]`: seu número direto ou link de agenda
